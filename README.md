# Capstone Project

My Flyrank AI Front-end Internship Github Repo

## Tech Stack

**Frontend**
- React
- JavaScript
- Tailwind CSS
- Vite
- React Router

**Backend**
- Node.js
- Python

## Getting Started

```bash
# clone the repo
git clone https://github.com/jwsephdev/flyrank-frontend-ai-capstone.git

# install dependencies
npm install

# start the dev server
npm run dev
```

## Settings

Open **Settings** in the nav to edit display name, email, theme (light/dark), and email notifications. Values are validated on save and stored in the browser via `localStorage`.
